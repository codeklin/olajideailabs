# Olajide AILabs

> Practical AI workflows and digital product monetization built for African creators, freelancers, and professionals. Starting with the phone in your hand.

---

## What is Olajide AILabs?

Most AI tutorials online assume an ideal environment: high-end laptops, unlimited high-speed fiber internet, and access to international payment platforms like Stripe or PayPal.

In Nigeria and across Africa, the reality is different. A capable laptop costs over ₦1.5M, foreign dollar cards fail regularly, and power is inconsistent. Yet millions of hungry, ambitious creators and professionals hold powerful smartphones in their hands every single day.

**Olajide AILabs** exists to bridge this gap. We teach practical, mobile-first AI workflows that allow anyone to move from passive consumers of AI technology to active builders who create and sell monetizable digital assets using free tools and local payment infrastructure.

---

## Core Friction Points We Solve

1. **Hardware Accessibility:** Removing the belief that you need an expensive computer to start building. Every core workflow is designed for mobile devices.
2. **Subscription Avoidance:** Bypassing expensive $20/month SaaS platforms that require international credit cards. We focus on high-yield, free AI tools.
3. **Execution Over Theory:** Replacing vague "learn AI" motivational advice with step-by-step blueprints for real products.
4. **Local Monetization:** Connecting finished digital assets directly to accessible African rails like **Nestuge** and **Selar**, enabling direct bank payouts.

## Tech Stack & Architecture

- **Framework:** Next.js (App Router)
- **UI & Runtime:** React 19, TypeScript
- **Styling:** Tailwind CSS with custom CSS variables
- **Motion:** Framer Motion for lightweight, weightless hover states
- **Icons:** Lucide React (strictly utilitarian, zero generic AI hype icons)

## Getting Started Locally

### Prerequisites
- Node.js 18+ or 20+
- pnpm (`corepack enable pnpm` or `npm install -g pnpm`)

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/olajideailabs/olajideailabs.git

# Navigate into the project
cd olajideailabs

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
pnpm build
pnpm start
```
